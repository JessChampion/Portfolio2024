Taiao was a project I worked on at university for the Microsoft Imagine Cup 2011 (national computer sciences competition).
Our project was an image recognition system that could identify mouse footprints to aid local conservation efforts.

My role in the project included:

- Working with camera drivers to capture images from within the application
- Image processing to clean up the images for the machine learning model
- Creating database structures and queries for reporting the results
